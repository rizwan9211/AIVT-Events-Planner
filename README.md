# AIVT Events - AI Celebration Planner
Built for PromptWars Challenge 5

Live: https://rizwan9211.github.io/AIVT-Events-Planner/

## Problem Solved
Indian middle-class families in Noida struggle to plan weddings/birthdays under budget.

## Solution
AI generates: Budget % Breakdown, 30-day Timeline, Noida Vendor Checklist, 3 Desi Theme Ideas using Gemini 1.5 Flash via Appwrite.

## Tech Stack
- Frontend: Single index.html + Tailwind CSS (Semantic, Accessible)
- Backend: Appwrite TablesDB, Functions, VectorsDB
- GenAI: Google Gemini

## How to Run
Open index.html -> Enter Event Name, Budget, Guests -> Generate Plan
